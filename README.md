# 🌧️ Rain Alarm

A simple rain detection and alarm system using a rain sensor, BC547 transistor, NE555 timer IC, and buzzer.

## 📌 Project Overview

The Rain Alarm detects the presence of rain using a rain sensor. 
When rainwater falls on the sensor, the sensor output changes and activates the BC547 transistor. 
The transistor triggers the NE555 timer, which drives the buzzer to produce an alarm.

## 🛠️ Components

- Rain Sensor
- NE555 Timer IC
- BC547 Transistor
- Buzzer
- 9V Battery
- Breadboard
- 10 µF Capacitor
- 470 Ω Resistor
- 1 kΩ Resistor
- 4.7 kΩ Resistor
- 100 kΩ Resistor

## ⚙️ Working Principle

1. The rain sensor detects water droplets.
2. The sensor changes the transistor input condition.
3. BC547 switches according to the sensor signal.
4. The NE555 timer is triggered.
5. The buzzer produces an alarm sound.
6. Therefore, the system indicates the presence of rain.

## 🎯 Applications
